## 2. Description du Service & Rôle de l'Agent IA
OpérIA est un progiciel d'assistance opérationnelle basé sur l'intelligence artificielle agentique. Il fournit :
- L'analyse automatisée de données d'entreprises via connecteurs MCP ;
- La préparation structurée d'opérations métier (brouillons de relance, propositions d'exports, synthèses) ;
- Un mécanisme de contrôle humain obligatoire préalablement à toute action externe.
